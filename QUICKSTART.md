# EasyIPTV Quick Start

A 1-minute guide to keeping your site running.

## Everyday Tasks

### 1. Changing Prices
File: `components/home/home-pricing.tsx`
*   Find the price you want to change (e.g., `$19.99`).
*   Type over it with the new price.
*   Save the file.

### 2. Changing Contact Info
File: `components/contact/contact-info.tsx`
*   Update your email or support links there.

### 3. Adding a Review
File: `components/home/home-reviews.tsx`
*   Copy an existing review block and paste a new one with the customer's name and comment.

## How to Publish Changes
1.  **Save** your files.
2.  **Git Commit**: "Updated prices" (or whatever you did).
3.  **Git Push**: Send it to GitHub.
4.  **Done**: Your site updates itself automatically!
